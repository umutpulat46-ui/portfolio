# Kenan Umut Pulat — Portfolio (TR / EN)

Personal portfolio website built with **Next.js 15**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Three.js**.

## Highlights

- **Bilingual (`TR` / `EN`)** experience with URL query (`?lang=en` / `?lang=tr`) and local persistence.
- **Interactive 3D Kinetic Scene** built with Three.js PBR materials (`Modular`, `Hub & Orbit`, and `Full-Stack` formations).
- **Scroll-Stacking Project Showcase** & slide-over case study drawer featuring real production platforms (`Ravion Digital Media`, `Foodactor`, `Kinetic Fuel Group`, `Sunbeam Innovations`) and open-source work (`Maritime Safety Tracker`).
- **Downloadable PDF Resumes** in both Turkish and English (`/public`).

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run start
```
